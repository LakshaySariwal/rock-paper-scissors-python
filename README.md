# Rock Paper Scissors – Python 🪨📄✂️

A simple command-line Rock Paper Scissors game written in Python.

## Features
- User vs Computer gameplay
- Random choice generation
- Input validation

## Concepts Used
- if-else conditions
- loops
- random module

## How to Run
1. Clone the repository
2. Run: python main.py
